# 阈值日志

目的：给全库的经验阈值攒实测背书（003 打断/纠正次数、005 diff 行数与审读时长、032 `/context` 差值、043 停手线、062 换模型信号、082 观察窗）。每次任务花 30 秒记一行，攒满两周按分布回填各篇。

记法：一次「AI 任务」结束（合并/放弃/停手）就记一行。

| | | | | | | | |

回填对照表（攒够 ≥20 行后做）：

- diff 行数分布的「审读时间陡增拐点」→ 回填 005 的「200-300 行」
